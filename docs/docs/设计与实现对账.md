# 冰箱清库存食谱助手 · 设计与实现对账（做了哪些 / 没做哪些）

> 文档定位：把**旧设计文档**（`需求规格说明书 v4.0`、`系统设计说明书 v0.2`、`架构设计说明书 v0.2`、`洞察报告 v4.0`）与 **`C:\codes\demo` 真实实现**逐条对账，回答两个问题：**哪些做了、哪些没做**。
> 文档版本：**校准-v1.0**
> 编制日期：2026-09-24
> 上游文档：同目录《需求规格说明书（校准版）》《架构设计说明书（校准版）》
> 事实优先级：**代码 > `.codegenie/MEMORY.md` > 文档**。

## 判定口径

| 标记 | 含义 |
| --- | --- |
| ✅ **做了** | 已实现，且与旧设计意图基本一致 |
| 🔶 **做了但不一样** | 已实现，但口径/形态/数据与旧设计不同（主动收敛、简化或替换） |
| ❌ **没做** | 旧设计要求的能力尚未实现 |
| ⚠️ **没验证** | 代码存在但未真机/未实测跑通 |

> 「🔶」不等于缺陷，多数是为「清库存优先」原则或 Demo 可行性主动收敛；「❌/⚠️」是真实缺口，不美化。

## 1. 总览

### 1.1 需求实现统计

| 层级 | 总数 | ✅ 做了 | 🔶 做了但不一样 | ❌ 没做 | ⚠️ 没验证 |
| --- | --- | --- | --- | --- | --- |
| 功能性需求 FR | 27 | 19 | 5 | 3 | —（部分含未验证项） |
| 非功能性需求 NFR | 12 | 8 | 3 | 1 | NFR-07 / NFR-10 含未验证 |
| 反向需求 RQ | 9 | 8 | 1（RQ-02 口径变） | 0 | — |

> 说明：FR-20 主能力（自动差集 + 进度 + 周度）已做，其**降级路径未接线**，计入 NFR-12 缺口。

### 1.2 一句话结论

- **主链路做全了**：拍照识别 → 校对 → 快照 → 生成 → 候选/详情 → 自动差集 → 反馈，全部打通（编译验证）。
- **最有价值的差异化做全了**：零维护库存（自动差集）、缺材宽容、便当单开关、临期优先。
- **补货分支被「做成了另一件事」**：从旧设计的「库存无法成菜时 ≤2 样、仅展示」变成「单道菜缺 1~4 样、带价格、可加入库存并重算缺项」。
- **明确没做**：临期列表排序（FR-06）、口味偏好（FR-16）、步数实测（FR-23）、离线态（NFR-03）、名称稳定性实测与降级接线（NFR-12）。
- **架构层与旧设计差异较大**：页面结构、适配层目录、Prompt 组织、DO 字段 schema、种子数量、视觉调用方式均与旧设计不同。
- **补货全链路尚未真机验证**。

### 5.3 接口契约

| 旧设计 | 真实实现 | 结论 |
| --- | --- | --- |
| IF-02 图片 `detail:low/high` + 单图 ≤1024 token | 客户端长边 1568 + JPEG 80，**不带 `detail`** | 🔶 做偏 |
| IF-02 视觉用 `deepseek-flash` 原生 Vision（前置门已过） | 配置驱动；**DeepSeek 官方接口不接受 `image_url`**，需指向支持图片的服务商/网关 | ❌ 旧前提不成立 |
| IF-03 与识别同一 `deepseek-flash` | 识别/生成可配**不同模型**（`visionModel` / `generationModel`） | 🔶 增强 |
| IF-02/03 单一 DeepSeek 服务 | `llm.json` **三服务商** + 运行时覆盖 + 「跟随配置」 | ✅ 做了且超出 |
| 固定 20s 级超时 | **识别/生成分离超时**（`readTimeoutMs` / `generationReadTimeoutMs`） | ✅ 做了且超出 |
| 错误码表 `IF02_400_IMAGE_POSITION` 等自有编号 | 无自有编号，映射到真实网络错误码 `2300055/2300028/2300005/2300006/2300003/2300060` + HTTP 400/401/403/413/429 | 🔶 做了但不一样 |
| IF-06 `buildReplenishment` / `showSourceCard` 网关 | 无该接口；来源与价格在补货页内联 | ❌ 没做 |

## 9. 结论与建议补齐顺序

**结论**：核心产品链路与差异化能力**已做**；未做项集中在 `① 验证类`（名称稳定性、5s、步数、真机）与 `② 简化替换类`（离线态、口味偏好、列表排序、营养/省钱展示、网关接口）。

**建议补齐顺序**：

1. **真机跑通补货全链路**（FR-26 / NFR-10）— 唯一未验证的核心链路。
2. **名称稳定性实测 + 降级接线**（NFR-12 / FR-20）— 自动差集的前提，否则逻辑不闭环。
3. **营养「估算值」标注**（FR-18）— 低成本、直接对齐验收。
4. **离线/弱网态**（NFR-03）— 承诺级能力，缺失明显。
5. **临期列表排序**（FR-06）与**口味偏好**（FR-16）— P1 余量项。
6. **省钱徽章/周报**（FR-19）— P2，可最后做。
7. **交付前清空 `llm.json` 真实 `sk-` Key**（安全，必须）。

> 逐条证据与验收口径见同目录《需求规格说明书（校准版）》附录 B/C 与《架构设计说明书（校准版）》§12。
